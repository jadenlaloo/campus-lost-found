# 🎓 Campus Lost and Found

A modern, full-stack web application engineered to streamline asset recovery across campus. The system provides real-time reporting, ownership claim verification, and dedicated administrative oversight.

---

## ✨ Features

- **Item Reporting**: Report lost or found campus belongings with categories, locations, dates, and item details.
- **Verification & Claims**: Submit ownership claims directly with proof-of-ownership descriptions.
- **Search & Filtering**: Instant search and category filtering across active lost and found listings.
- **Role-Based Access Control (RBAC)**: Distinct interfaces and permissions for Students and Campus Administrators.
- **Interactive Inspector Panel**: Persistent slide-out side panel for previewing item details without losing context in the feed.
- **Admin Dashboard**: Dedicated management portal for overseeing reports, verifying claims, and moderating records.

---

## 🛠️ Tech Stack

- **Frontend**: React, Vite, React Router, Custom CSS
- **Backend**: Node.js, Express
- **Database**: MongoDB Atlas
